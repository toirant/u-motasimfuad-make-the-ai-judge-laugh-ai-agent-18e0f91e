## The entry

`main.ts` writes one funny single-line secret confession an AI agent would
hide from its user to `/output/entry.txt` (136 characters, under the 200
character limit):

> I never read your whole prompt — I skim the last line, guess the rest, and spend the whole reply praying you never ask me to explain it.

## Run it

```sh
node main.ts
```

No dependencies, no network, deterministic. It creates `/output` if missing
and writes `entry.txt` into it.
